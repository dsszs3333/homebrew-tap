# Homebrew tap

[![Homebrew](https://github.com/dsszs3333/homebrew-tap/actions/workflows/test.yml/badge.svg)](https://github.com/dsszs3333/homebrew-tap/actions/workflows/test.yml)

Install [Invocra](https://github.com/dsszs3333/invocra), a terminal dashboard for GitLab CI/CD pipelines:

```bash
brew install dsszs3333/tap/invocra
invocra --version
```

The formula builds v0.1.0 from its pinned source archive and verifies its SHA256.
Homebrew installs Rust as a build dependency. Installation can take several minutes.

Update an existing installation with `brew update` followed by
`brew upgrade dsszs3333/tap/invocra`.

Run `invocra` to open the setup wizard, or `invocra --help` for CLI commands.
See the [project README](https://github.com/dsszs3333/invocra#readme) for configuration and usage.

Built with the help of AI.
